# TallyBard

Open-source collections copilot for people who sell on credit.

## Status

This is a work in progress, started on 2026-10-15 for the Hacktoberfest Open-Source AI Challenge Week 2 (Side Hustle).

## Planned stack

- Mastra (agent and workflow)
- Gemma via Ollama or Google AI Studio
- TabPFN (late-payment risk scoring)
- Tiger Data Postgres (pgvector and hybrid search)
- Sentry Agent Tracing
- Render (hosting)
- DigitalOcean (GPU Droplet for open models)

## Privacy

Client names, phone numbers, and notes stay on infrastructure the user controls, and only anonymised numeric features are sent to any prediction API.

## Data

All demo data is synthetic and will be labelled as such.
